## Introduction

L'agent d'embarquement est responsable de vérifier les billets et les bagages avant l'embarquement des passagers. Ce guide détaille les procédures à suivre.

⚠️ **Note :** Ce rôle peut être assuré par un administrateur ou un caissier selon l'organisation de l'agence.

---

## Rôle de l'agent d'embarquement

### Responsabilités principales

- Vérifier la validité des billets
- Contrôler les bagages enregistrés
- Assurer le bon ordre d'embarquement
- Gérer les situations exceptionnelles
- Communiquer avec le conducteur

### Compétences requises

- Maîtrise de l'interface NGOKAF TRANS
- Connaissance des procédures de l'agence
- Capacité à gérer les situations stressantes
- Communication efficace

## Vérification des billets

### Scanner un billet

1. Ouvrez NGOKAF TRANS
2. Connectez-vous avec votre compte
3. Allez dans la section appropriée (selon votre rôle)
4. Utilisez le lecteur de code QR ou entrez le numéro manuellement
5. Les informations du billet s'affichent

### Informations à vérifier

Pour chaque billet, vérifiez :

- **Numéro de billet** : Unicité et validité
- **Nom du passager** : Correspondance avec la pièce d'identité
- **Trajet** : Origine et destination correctes
- **Date et heure** : Correspondance avec le voyage actuel
- **Siège** : Numéro de siège assigné
- **Statut** : Billet non annulé

### Procédure de validation

1. Demandez la pièce d'identité du passager
2. Scannez ou entrez le numéro de billet
3. Vérifiez que toutes les informations correspondent
4. Confirmez la validité du billet
5. Autorisez l'embarquement

### Billet invalide

Si le billet est invalide :

- **Billet annulé** : Informez le passager, demandez un nouveau billet
- **Mauvais trajet** : Redirigez vers le bon guichet
- **Date incorrecte** : Informez le passager de la date correcte
- **Billet déjà utilisé** : Signalez l'incident à l'administrateur

## Contrôle des bagages

### Vérifier l'étiquette de bagage

Pour chaque bagage, vérifiez :

- **Numéro d'étiquette** : Correspond au billet
- **Poids** : Conforme à l'enregistrement
- **Destination** : Correspond au trajet
- **État** : Pas de dommage visible

### Procédure de contrôle

1. Demandez l'étiquette de bagage
2. Scannez ou entrez le numéro
3. Vérifiez les informations
4. Contrôlez visuellement le bagage
5. Validez le bagage pour embarquement

### Bagage sans étiquette

Si un bagage n'a pas d'étiquette :

1. Demandez le billet du passager
2. Vérifiez si le bagage a été enregistré
3. Si non enregistré :
   - Demandez au passager de l'enregistrer au guichet
   - Ou enregistrez-le vous-même si autorisé
4. Si enregistré mais sans étiquette :
   - Réimprimez l'étiquette
   - Collez-la sur le bagage

### Bagage endommagé

Si un bagage est endommagé :

1. Documentez l'état du bagage
2. Informez le passager
3. Signalez à l'administrateur
4. Prenez des photos si nécessaire
5. Notez l'incident dans le journal

## Gestion de l'embarquement

### Ordre d'embarquement

Recommandé ordre d'embarquement :

1. **Passagers prioritaires** : Personnes âgées, femmes enceintes, personnes à mobilité réduite
2. **Passagers avec sièges numérotés** : Selon le numéro de siège
3. **Passagers sans réservation** : Selon l'ordre d'arrivée

### Communication avec le conducteur

Avant le départ :

1. Confirmez le nombre de passagers embarqués
2. Signalez tout problème ou retard
3. Vérifiez que tous les bagages sont chargés
4. Confirmez que le bus est complet ou prêt à partir

### Liste d'embarquement

Utilisez le système pour :

- Générer la liste des passagers embarqués
- Vérifier les passagers absents
- Identifier les sièges disponibles
- Confirmer le nombre total de passagers

## Situations exceptionnelles

### Passager absent

Si un passager ne se présente pas :

1. Attendez 15 minutes après l'heure de départ
2. Vérifiez si le billet peut être annulé
3. Libérez le siège si autorisé
4. Notez l'incident
5. Informez l'administrateur

### Surbooking

Si plus de passagers que de sièges :

1. Identifiez les passagers sans réservation
2. Expliquez la situation
3. Proposez des alternatives :
   - Prochain bus
   - Remboursement
   - Upgrade si disponible
4. Informez l'administrateur

### Bagage perdu

Si un bagage est introuvable :

1. Vérifiez à nouveau les enregistrements
2. Demandez au passager de décrire le bagage
3. Cherchez dans les zones de stockage
4. Signalez comme perdu si introuvable
5. Documentez l'incident
6. Informez l'administrateur

### Passager refusant d'embarquer

Si un passager refuse de monter :

1. Écoutez la raison du refus
2. Expliquez les politiques de l'agence
3. Proposez des solutions
4. Si le refus persiste :
   - Annulez le billet si approprié
   - Remboursez selon la politique
   - Documentez l'incident

### Problème technique

Si le système ne fonctionne pas :

1. Utilisez la procédure manuelle de secours
2. Documentez tous les billets manuellement
3. Informez immédiatement l'administrateur
4. Saisissez les données dans le système dès que possible

## Sécurité

### Règles de sécurité

- Ne permettez jamais l'embarquement sans billet valide
- Signalez tout comportement suspect
- Ne laissez pas de bagages sans surveillance
- Suivez les procédures d'urgence
- Portez un équipement de sécurité si requis

### Urgences

En cas d'urgence :

1. Suivez les procédures d'urgence de l'agence
2. Évacuez si nécessaire
3. Contactez les services d'urgence
4. Informez l'administrateur
5. Documentez l'incident

## Communication

### Avec les passagers

- Soyez courtois et professionnel
- Expliquez clairement les procédures
- Répondez aux questions
- Restez calme en toutes circonstances

### Avec l'équipe

- Communiquez tout problème immédiatement
- Documentez les incidents
- Partagez les informations importantes
- Collaborez avec les autres agents

## Rapports

### Rapport d'embarquement

À la fin de chaque embarquement :

1. Générez le rapport d'embarquement
2. Vérifiez les statistiques
3. Notez任何 incident
4. Soumettez à l'administrateur

### Statistiques à suivre

- Nombre de passagers embarqués
- Nombre de bagages enregistrés
- Incidents survenus
- Retards
- Billets annulés
